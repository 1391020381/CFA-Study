## 一、核心概念

### 1. 风险承受能力

**定义：** 你能承受多大损失而不影响生活和心态

**两个维度：**

| 维度 | 问题 | 自测结果 |
|-----|------|----------|
| **财务能力** | 跌50%影响生活吗？ | ✅ 不影响（大额存单是安全垫） |
| **心理承受** | 跌的时候睡不着吗？ | ✅ 能接受（选C，想加仓） |

**关键公式：**
> 真正的承受 = 你以为的承受 × 0.6

因为纸面亏损和真实感受是两回事。

### 2. 投资目标的SMART原则

好的投资目标应该：

| 原则 | 含义 | 示例 |
|-----|------|------|
| **S** 具体的 | 明确数字 | 年化 8-10% |
| **M** 可衡量 | 能量化的 | 跑赢CPI 2-3% |
| **A** 可实现的 | 不盲目 | 合理预期 |
| **R** 相关的 | 与人生目标相关 | 养老储备 |
| **T** 有时限 | 投资期限 | 5年以上 |

**我的SMART目标：**
> 在5年以上的投资期限内，通过50%沪深300+50%红利的配置，实现年化8-10%的收益，跑赢通胀2-3个百分点。

### 5. 择时方法

#### PE分位数判断市场位置

**怎么看：**
- 支付宝 → 基金 → 指数红绿灯
- 蛋卷基金 → 搜索"沪深300"
- 同花顺 → 沪深300 → F10/估值

**判断标准：**
```
PE分位数 < 20%  → 极度低估，大买
PE分位数 20-40% → 低估，多买
PE分位数 40-60% → 合理，正常买
PE分位数 60-80% → 高估，少买或不买
PE分位数 > 80%  → 极度高估，考虑卖出
```

**当前（2024）：** 沪深300 PE分位数约30-40% → 合理偏低，适合分批买入

#### 均线偏离度

```
价格 < 250日均线 × 0.9 → 深度回调，快买
价格在 250日均线附近  → 合理位置，正常买
价格 > 250日均线 × 1.1 → 高位，少买
```

---

### 6. 买入节奏

**我的策略：看市场情况，跌就快买，涨就慢买**

结合PE分位数：

| PE分位数 | 买入节奏 | 完成时间 |
|---------|---------|----------|
| < 30% | 快买 | 3-6个月 |
| 30-60% | 正常买 | 6-12个月 |
| > 60% | 慢买或不买 | 12个月+ |

---

### 7. 再平衡机制

**定义：** 定期调整资产配置比例，恢复到目标配置

**举例：**
```
初始配置：沪深300 10w（50%）+ 红利 10w（50%）

一年后：沪深300 14w（58%）+ 红利 10w（42%）

再平衡：卖掉2w沪深300，买入2w红利
恢复到 50%:50%
```

**再平衡时机：**
- 每年固定时间（如每年1月）
- 偏离超过5%（某个资产>55%或<45%）
- 市场极端情况

**再平衡的好处：**
1. 高抛低吸（涨多的卖掉，买涨少的）
2. 控制风险（避免单一资产占比过高）
3. 纪律执行（避免情绪化操作）
