# 第21讲：打新与可转债

### 学习日期
2026-03-04

### 核心概念

#### 一、打新（IPO申购）

##### 什么是打新？
"打新"就是参与IPO申购，在新股上市前按发行价买入，上市首日卖出赚钱。

##### 为什么能赚钱？
A股有"新股不败"的传统——新股上市首日几乎都会上涨。
1. **发行价被人为压低**（监管层为了保护散户）
2. **新股稀缺**（大家都想买，供不应求）
3. **炒新 tradition**（A股散户喜欢炒新）

##### 打新条件
| 要求 | 具体规定 |
|------|----------|
| **股票市值** | 沪市/深市分别需要≥1万元市值（T-2日前持有） |
| **申购额度** | 每1万元市值=1000股申购额度 |
| **中签率** | 通常0.01%-0.05%（很低！） |
| **资金要求** | 中签后才需缴款 |

##### 打新策略
**"两头配"策略**：
- 持有沪深两市各10-20万市值股票
- 每天都参与打新申购
- 中签就缴款，上市首日就卖出

##### 底仓选择建议
| 策略 | 底仓选择 | 优点 | 缺点 |
|------|----------|------|------|
| 大盘股 | 银行、石油、电力 | 波动小，打新稳定 | 收益低 |
| **推荐** | 沪深300ETF | 分散风险，长期持有 | - |
| 高股息 | 长江电力、神华 | 打新+分红 | 股价波动 |

#### 二、可转债

##### 可转债本质
可转债 = **债券 + 看涨期权**
- **债性**：到期还本付息（保底）
- **股性**：可以转换成股票（上涨空间）

##### 可转债价格结构
```
┌─────────────────────────────────┐
│  上涨空间：跟随正股上涨           │  💎 股性
├─────────────────────────────────┤
│  转股价：100元                    │
├─────────────────────────────────┤
│  下跌保护：到期还本+利息（约105元）│  🛡️ 债性
└─────────────────────────────────┘
```

##### "进可攻、退可守"的含义
- **退可守**：正股跌了，不转股，拿回本金（最多亏点利息）
- **进可攻**：正股涨了，转成股票或卖掉可转债，享受上涨

##### 可转债时间轴
```
发行 ─────┬────── 6年 ─────┬────→ 到期
          │                  │
        转股期            到期还本
        （发行6个月后      （100元+利息）
         才能转股）
```

##### 可转债投资选择
1. **持有**：当普通债券，到期拿回本金+利息
2. **转股**：把债券换成股票，享受股价上涨
3. **卖出**：直接在市场上卖掉可转债

---

#### 三、可转债打新

##### 优势
- ✅ **无需市值**：空仓也能申购
- ✅ **中签率高**：比股票打新高10倍左右
- ✅ **风险低**：上市首日破发概率小

##### 操作流程
```
每天查看有无可转债发行
→ 点击申购
→ 中签后缴款（1000元起）
→ 上市首日卖出（通常赚10-30%）
```

### 理解检查

- [x] 打新 vs 买新股的区别（打新是IPO发行阶段按发行价，买新股是上市后按市场价）
- [x] 可转债"进可攻、退可守"的含义（债性保底+股性上涨空间）
- [x] 可转债到期和期间的区别（到期还本，期间可选择持有/转股/卖出）
- [x] 打新底仓配置策略（沪深各10-20万市值，选低波动标的）
- [x] 新股破发风险（注册制后破发概率增加，需要筛选）

### 实践应用

#### 💡 投资策略

##### 打新策略
1. **底仓配置**：沪深300ETF各10-20万
2. **每日申购**：坚持每天参与打新
3. **首日卖出**：上市首日开盘即卖出，不贪婪
4. **新股筛选**：避开高估值、亏损企业

##### 可转债策略
1. **可转债打新**：每天申购，中签后上市首日卖出
2. **可转债投资**（进阶）：
   - 双低策略（价格低、溢价率低）
   - 持有到期（年化2-3%，比银行好）
   - 等待强赎（价格涨到130+）

#### ⚠️ 风险提示
1. **新股破发**：现在有10-20%新股首日破发风险
2. **底仓波动**：打新底仓会随市场波动
3. **中签率低**：股票打新中签率很低，需要耐心
4. **资金占用**：中签后需要冻结资金

### 学习心得

> **打新和可转债不是主要投资方式，而是辅助策略**
>
> - 打新收益 = 运气成分大，不稳定
> - 底仓波动 > 打新收益，市场大跌时得不偿失
> - 正确做法：以长期投资为主，打新为辅的"增强收益"策略
>
> **如果只为了打新而买股票，本末倒置。应该是先有长期投资计划，打新只是顺便的额外收益。**

**关键领悟**：低风险套利策略（打新、可转债）应该是投资组合的"甜点"，而不是主食。长期投资优质资产才是正道。
