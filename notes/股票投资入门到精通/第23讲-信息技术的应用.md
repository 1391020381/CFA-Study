#### 二、技术分析基础

##### K线图基础
```
        上影线
          │
    ┌─────┴─────┐  ← 实体（红色涨，绿色跌）
    │           │
    └─────┬─────┘
          │
        下影线
```

- **实体**：开盘价到收盘价
- **上影线**：当天最高价
- **下影线**：当天最低价

##### 常见技术指标
| 指标 | 全称 | 作用 | 可靠性 |
|------|------|------|--------|
| MA | 均线 | 平滑价格波动 | ⭐⭐ |
| MACD | 指数平滑异同移动平均线 | 判断趋势 | ⭐⭐ |
| KDJ | 随机指标 | 超买超卖 | ⭐ |
| 成交量 | Volume | 验证涨跌真实性 | ⭐⭐⭐ |

##### ⚠️ 技术分析的三大问题

**1. 滞后性**：K线反映的是过去，不能预测未来
**2. 主观性**：同一张图，10个人有10种看法
**3. 幸存者偏差**：你只看到成功案例，失败者不会说话

##### 巴菲特的观点
> "我从不对图表做技术分析。我对所谓的技术分析持怀疑态度。"

##### 建议
了解基本概念即可，不要沉迷。**PE估值方法更靠谱！**

#### 三、量化入门

##### 什么是量化交易？

**传统投资**：
```
研究 → 分析 → 决策 → 买卖
  ↓
凭经验和判断
```

**量化交易**：
```
数据 → 策略 → 回测 → 程序自动交易
  ↓
用数学和代码
```

##### 量化策略举例

**简单策略**：
```
如果 PE < 15 且 ROE > 20%：
    买入
如果 PE > 30：
    卖出
```

**复杂策略**：用机器学习分析新闻情绪、资金流向、行业轮动...

##### 量化交易的优缺点

| 优点 | 缺点 |
|------|------|
| 克服人性弱点 | 过度拟合历史数据 |
| 执行速度快 | 需要编程和数学能力 |
| 可回测验证 | 竞争激烈，收益递减 |
| 分散投资 | 黑天鹅事件可能失效 |

##### 给新手的建议
```
┌─────────────────────────────────────────────┐
│  量化交易：了解即可，不建议新手尝试         │
├─────────────────────────────────────────────┤
│  原因：                                      │
│  1. 需要编程能力（Python、SQL）             │
│  2. 需要数学基础（统计学、概率论）           │
│  3. 需要大量数据清洗工作                    │
│  4. 普通投资者很难与机构竞争                 │
│                                             │
│  如果你感兴趣：                              │
│  - 先学好Python                              │

│  - 用tushare等免费数据源练习                │
└─────────────────────────────────────────────┘
```

### 实践应用

#### 💡 投资理念

**核心观点**：
> "技术手段在股票投资领域是作为辅助手段。主要还是看分析公司内在价值。"

**技术分析 vs 价值投资**：
```
技术分析：开车看后视镜
价值投资：看挡风玻璃和导航

后视镜（过去）能告诉你路况，但不能告诉你前面怎么走
```

#### ⚠️ 投资纪律
1. **工具是辅助**：不要被花哨的技术指标迷惑
2. **专注本质**：公司内在价值才是核心
3. **坚持方法**：PE估值+基本面分析更可靠
4. **保持清醒**：知道什么不学，比知道什么都学更重要
