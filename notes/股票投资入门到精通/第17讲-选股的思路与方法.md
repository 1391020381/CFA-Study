## 一、核心概念

### 1. 选股的两种思路

#### 自上而下
```
先选行业 → 再选公司 → 最后看价格
```
**适合人群：** 喜欢研究宏观、行业的人

#### 自下而上 ⭐（推荐散户）
```
先选好公司 → 再看行业 → 最后看价格
```
**适合人群：** 散户、新手、生活化投资者

---

### 2. 好公司 ≠ 好股票

| 好公司 | 好股票 |
|-------|--------|
| 业务好、赚钱多、有护城河 | 好公司 + 便宜的价格 |
| 但可能太贵 | 价格被低估 |
| 买入不赚钱 | 买入能赚钱 |

**好股票 = 好公司 + 好价格**

---

### 3. 好公司的标准（巴菲特）

| 标准 | 含义 | 检查方法 |
|-----|------|----------|
| **业务简单易懂** | 你能说清它怎么赚钱 | 能用一句话说清 |
| **有护城河** | 竞争对手进不来 | 品牌、网络效应、转换成本、成本优势 |
| **盈利稳定** | 持续赚钱 | ROE常年>15% |
| **少负债** | 不靠杠杆活着 | 资产负债率合理 |
| **管理层诚信** | 不会坑股东 | 分红大方，不乱搞 |

---

### 4. 好价格的标准

#### 估值三问

**1. 和历史比，贵不贵？**
- PE、PB的历史分位数
- < 30%：便宜
- > 70%：贵

**2. 和同行比，贵不贵？**
- 同行业公司的PE对比

**3. 和成长性比，贵不贵？**
- PEG = PE / 增长率
- PEG < 1：便宜
- PEG > 2：贵

#### 安全边际公式
```
合理价格 = 保守估计的内在价值
买入价格 = 合理价格 × 0.8  ← 打8折留安全边际
```

## 二、我的选股流程

### 第1步：从身边发现好公司

- PEG指标
- 同行对比

- 耐心等待低估值
- 或分批买入

## 四、克服完美主义

### ❌ 完美主义的陷阱

| 想法 | 问题 |
|-----|------|
| "等跌到最低点买" | 最低点只有事后才知道 |
| "等确认涨势再买" | 那时已经涨了很多 |
| "等所有消息都明朗" | 永远没有明朗的时候 |

> **"完美是优秀的敌人。"** — 伏尔泰

### ✅ 正确的择时观

```
好的时机 ≠ 最好的时机 ≠ 最低点

好的时机 =
  估值合理偏低
  + 公司基本面没问题
  + 市场情绪悲观
  + 你能拿3年以上
```

### 📊 择时的不可能三角

| 完美的择时 | 现实 |
|-----------|------|
| 买在最低点 | ❌ 不可能 |
| 卖在最高点 | ❌ 不可能 |
| 吃到全部涨幅 | ❌ 不可能 |
| **吃到中间60%** | ✅ 可以做到 |

## 五、解决不敢下单的方法

### 方法1：分批买入
```
第1批（30%）：现在就买，不管价格
第2批（30%）：跌5%后再买
第3批（40%）：跌10%后再买
```

### 方法2：定期买入
```
不管价格如何，每个月固定买入
├─ 月初看一眼估值
├─ 如果便宜就买
├─ 如果太贵就不买
└─ 长期下来成本是平均的
```

### 方法3：设定纪律，严格执行
```
买入纪律写下来：
├─ PE < 15倍 → 买入
├─ PE 15-20倍 → 观望
├─ PE > 20倍 → 不买
└─ 到了条件就执行，不犹豫
```

## 六、实战案例：腾讯控股

### 第1步：公司熟悉度 ✅
| 问题 | 答案 |
|-----|------|
| 你用它的产品吗？ | 微信、QQ、王者荣耀、腾讯视频... |
| 你知道它怎么赚钱吗？ | 游戏、广告、金融科技（支付） |
| 你能说清它的业务吗？ | 能 |

### 第2步：行业分析
| 维度 | 分析 |
|-----|------|
| **行业周期** | 成长期 → 成熟期过渡（增速放缓但仍在增长） |
| **竞争格局** | 寡头垄断（腾讯+阿里+字节） |
| **护城河** | ✅ 网络效应（微信13亿用户）<br>✅ 转换成本（社交关系都在微信）<br>✅ 生态闭环（微信+游戏+支付+内容） |

### 第3步：财务分析（以2023年数据为例）
| 指标 | 数值 | 评价 |
|-----|------|------|
| **ROE** | ~15-20% | ✅ 优秀 |
| **毛利率** | ~45-50% | ✅ 轻资产，高毛利 |
| **资产负债率** | ~25% | ✅ 低负债 |
| **现金流** | 经营性现金流>净利润 | ✅ 赚真钱 |
| **分红** | 每年分红+回购 | ✅ 回报股东 |

### 第4步：估值
| 指标 | 当前（2024） | 历史分位数 | 评价 |
|-----|-------------|-----------|------|
| **PE** | ~13-15倍 | ~20-30% | ✅ 低估 |
| **PB** | ~2-3倍 | ~10-20% | ✅ 低估 |
| **PS** | ~3-4倍 | ~20-30% | ✅ 低估 |

### 第5步：决策
- 公司好 ✅
- 估值低 ✅
- **但不急着买**，继续观察

## 七、买卖纪律

### 买入纪律
```
条件1：好公司
  ├─ 业务简单易懂
  ├─ 护城河深
  └─ 财务健康

条件2：好价格
  ├─ PE分位数 < 30%
  ├─ PB分位数 < 20%
  └─ 比历史高点便宜50%+

条件3：好时机
  ├─ 市场情绪是否悲观？
  ├─ 有没有坏消息压制？
  └─ 你敢拿3年以上吗？

结论：如果3个条件都满足 → 分批买入
```

### 卖出纪律
```
卖出理由1：公司变坏了
  ├─ 护城河消失
  ├─ 业务恶化
  └─ 财务暴雷

卖出理由2：价格太贵了
  ├─ PE分位数 > 80%
  ├─ 远超内在价值
  └─ 有更好的标的

卖出理由3：自己犯了错
  ├─ 买错了（当初分析有误）
  ├─ 发现更好的机会
  └─ 需要用钱

**只要以上3条都不满足 → 继续持有**
```
