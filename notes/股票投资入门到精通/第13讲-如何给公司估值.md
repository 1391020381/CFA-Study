**学习日期**: 2026-02-28

## 学习目标

理解估值的本质，掌握相对估值和绝对估值两种方法，学会在实际投资中运用多种估值方法相互印证。

---

## 核心概念

### 1. 估值的本质

**估值 = 判断股价相对于公司价值，是贵还是便宜**

- 不是预测股价涨跌
- 而是判断价格是否合理
- 寻找价格低于价值的机会（安全边际）

### 2. 相对估值（实战最常用）

#### PE（市盈率）
```
PE = 股价 / 每股盈利
```
- 含义：几年回本
- 适用：稳定盈利的公司（消费、医药、成熟制造业）
- 参考标准：历史百分位 < 30% 低估
- 注意：要结合行业和增长率看

#### PB（市净率）
```
PB = 股价 / 每股净资产
```
- 适用：银行、券商、钢铁、煤炭等周期行业
- 不适用：互联网、服务业（轻资产）
- 参考标准：PB < 1.5 挖掘价值

#### PEG（市盈率相对盈利增长比率）
```
PEG = PE / 净利润增长率
```
- 适用：成长股（科技、新能源、消费品牌）
- 参考标准：PEG < 1 低估
- 案例：PE=15，增长20% → PEG=0.75（低估）

#### 股息率
```
股息率 = 每股分红 / 股价
```
- 适用：高分红公司（银行、公共事业）
- 参考标准：> 3% 有吸引力

#### PS（市销率）- 补充
```
PS = 股价 / 每股营收
```
- 适用：亏损但有营收的公司（早期科技股）
- 参考标准：PS < 3 倍（视行业而定）

### 3. 绝对估值 DCF（现金流折现）

#### 公式
```
公司价值 = Σ(未来现金流 / (1+折现率)^年数)
```

#### 核心思想
- 预测公司未来10年每年赚多少现金流
- 把未来的钱按利率"折现"成今天的价值
- 加起来就是公司"内在价值"

#### 钱的时间价值
- 今天的10万 > 明年的10万
- 折现率越高，未来现金流折现值越低
- 股票风险大，折现率通常用8%-12%

#### 计算示例
假设：未来10年每年10万现金流，折现率10%

| 年份 | 现金流 | 折现因子 | 现值 |
|------|--------|----------|------|
| 1 | 10万 | 1/1.1 | 9.09万 |
| 2 | 10万 | 1/1.1² | 8.26万 |
| 3 | 10万 | 1/1.1³ | 7.51万 |
| ... | ... | ... | ... |
| 10 | 10万 | 1/1.1¹⁰ | 3.86万 |
| **合计** | **100万** | | **61.45万** |

**结论**：10年赚100万，但折现到今天只值61.45万

#### DCF的优缺点
| 优点 | 缺点 |
|------|------|
| 理论最严谨 | 假设太多，敏感度高 |
| 考虑了时间价值 | 增长率预测很难 |
| 适合现金流稳定的公司 | 不适合亏损/高成长公司 |

---

## 估值方法适用场景总结

| 指标 | 适合场景 | 不适合 | 参考标准 |
|------|----------|--------|----------|
| PE | 稳定盈利公司 | 亏损公司、周期高点 | 历史百分位 < 30% 低估 |
| PB | 银行、券商、周期行业 | 互联网、服务（轻资产） | PB < 1.5 挖掘价值 |
| PEG | 成长股 | 增长不稳定或负增长 | PEG < 1 低估 |
| 股息率 | 高分红公司 | 不分红的公司 | > 3% 有吸引力 |
| PS | 亏损但有营收 | 成熟盈利公司 | PS < 3 倍（视行业） |
| DCF | 现金流稳定的公司 | 亏损、高成长公司 | 宁模糊正确 |

---

## 实战原则

### 应该做 ✅
- 多种方法交叉验证
- 和同行业对比
- 和历史对比
- 结合增长率看（PEG）
- 留足安全边际

### 不应该做 ❌
- 不孤立看单一指标
- 不迷信精确数字
- 不忽略行业特性

---

## 实战案例：多方法相互印证

### 腾讯控股估值（假设）

| 估值方法 | 结果 | 结论 |
|----------|------|------|
| PE（历史百分位） | 380港元 | 合理偏低 |
| PB | 420港元 | 合理 |
| DCF | 400港元 | 略低估 |
| **综合判断** | **≈400港元** | **有安全边际** |

**判断原则**：
- 如果各种方法结果接近 → 结论可信度高
- 如果结果差异很大 → 需要分析原因（可能是周期顶部/底部）

## 理解检查

### 问题1：PEG应用
A公司：PE=15倍，净利润增长20%
B公司：PE=15倍，净利润增长5%

**答案**：
- A公司：PEG = 15/20 = 0.75 < 1（低估）✅
- B公司：PEG = 15/5 = 3.0 > 1（高估）❌

### 问题2：亏损公司估值
PE为负数（亏损公司）时，应该用什么方法？

**答案**：
- PS（市销率）- 看营收
- 用户/DAU估值 - 互联网平台
- 看盈利路径 - 何时能盈利
- PB兜底 - 有资产支撑

**核心逻辑**：亏损不可怕，关键看：
1. 营收是否快速增长？
2. 什么时候能盈利？
3. 现金流能否撑到盈利？

## 实践应用

### 如何在真实投资中应用

1. **选股时**
   - 用PE筛选低估公司
   - 用PEG排除高估值成长股
   - 用PB挖掘周期股机会

2. **买入决策时**
   - 多种方法估值
   - 留足安全边际（至少20%）
   - 结合市场情绪判断

3. **持有/卖出时**
   - 定期重新估值
   - 注意估值回归风险
   - 不要因为PE高就盲目卖出（要看增长率）
