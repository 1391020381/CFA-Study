## 核心概念

### 1. 为什么要研究行业？

选对行业，投资就成功了一半。

```
好公司 + 好行业 = 大牛股的概率高
好公司 + 差行业 = 举步维艰
差公司 + 好行业 = 可能被淘汰
```

**行业对公司的意义**：
- 决定市场空间（天花板）
- 影响盈利能力（竞争程度）
- 关联发展速度（朝阳 vs 夕阳）

### 2. 申万行业分类

A股最常用的行业分类是**申万一级行业**，共31个。

| 大类 | 代表行业 |
|------|----------|
| 周期类 | 银行、地产、钢铁、煤炭、化工、有色 |
| 消费类 | 食品饮料、白酒、家电、旅游、零售 |
| 成长类 | 电子、计算机、传媒、通信、电力设备 |
| 金融类 | 银行、券商、保险 |
| 稳定类 | 公用事业、交通运输、建筑装饰 |

**重点行业与龙头**：
| 申万行业 | 龙头公司 | 特点 |
|----------|----------|------|
| 食品饮料 | 贵州茅台、五粮液 | 长期牛股集中营 |
| 银行 | 招商银行、工商银行 | 高股息、稳健 |
| 电力设备 | 宁德时代、隆基绿能 | 新能源、高成长 |
| 医药生物 | 恒瑞医药、迈瑞医疗 | 刚需、抗周期 |

### 3. 产业链分析

**新能源车产业链**：
```
上游（原材料）→ 中游（零部件）→ 下游（整车）→ 终端（消费者）
锂矿、钴矿        电池、芯片         特斯拉、比亚迪
天齐锂业          宁德时代           蔚来、小鹏、理想
```

**投资启示**：
- 上游：资源为王，价格波动大
- 中游：技术密集，竞争激烈
- 下游：品牌为王，赢者通吃

### 4. 竞争格局分析

**竞争程度与盈利能力**：

```
完全竞争 → 垄断竞争 → 寡头垄断 → 完全垄断
（低盈利）                     （高盈利）
```

| 竞争类型 | 特点 | 例子 | 投资价值 |
|----------|------|------|----------|
| 完全竞争 | 企业多、无差异化 | 农产品、普通制造 | 低 |
| 垄断竞争 | 有一定差异化 | 餐饮、服装 | 中 |
| 寡头垄断 | 几家大公司主导 | 高端白酒、社交软件 | 高 |
| 完全垄断 | 只有一家 | 电力、铁路 | 极高（但受监管） |

**白酒行业的竞争格局**：
- 高端：茅台几乎垄断（定价权）
- 次高端：五粮液、国窖1573竞争
- 中低端：区域酒企混战

### 5. 行业生命周期

```
导入期 → 成长期 → 成熟期 → 衰退期
高风险   高成长   稳定分红   谨慎投资
```

| 阶段 | 特点 | 代表行业 | 投资策略 |
|------|------|----------|----------|
| 导入期 | 技术不确定、亏损 | 量子计算、可控核聚变 | 风险投资 |
| 成长期 | 快速增长、竞争激烈 | 新能源车、AI | 寻找龙头 |
| 成熟期 | 增速放缓、格局稳定 | 银行、白酒 | 关注龙头+分红 |
| 衰退期 | 需求下降 | 胶卷、固定电话 | 避免 |

```
优选：寡头垄断 + 成熟期/成长期
  → 高端白酒、社交软件、高端医疗器械

次选：垄断竞争 + 成长期
  → 新能源车、部分消费品

谨慎：完全竞争
  → 普通制造、低端服务
```
