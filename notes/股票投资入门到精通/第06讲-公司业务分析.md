# 第06讲：公司业务分析

## 学习日期
2026-02-27

## 核心概念

### 什么是公司业务分析？
回答三个问题：
1. 这家公司是做什么的？— 产品/服务、赚钱方式
2. 它赚不赚钱？— 生意模式好不好
3. 它能持续赚钱吗？— 有没有护城河

### 四个核心分析维度

```
公司业务分析
├── 1. 商业模式：怎么赚钱？
│   ├── 卖什么产品/服务？
│   ├── 谁是客户？
│   └── 怎么收费？
│
├── 2. 竞争优势：比别人强在哪里？
│   ├── 成本更低？
│   ├── 产品更好？
│   └── 品牌更强？
│
├── 3. 护城河：优势能持续多久？
│   └── 护城河 = 可持续的竞争优势
│
└── 4. 管理层：掌舵人靠谱吗？
    ├── 诚信度
    ├── 能力
    └── 与股东利益一致
```

### 护城河的四种主要类型

| 类型 | 含义 | 真实案例 | 识别信号 |
|------|------|----------|---------|
| **品牌护城河** | 愿意为品牌多付钱 | 茅台、爱马仕、可口可乐 | 能提价还不丢单 |
| **网络效应** | 用户越多越有价值 | 微信、淘宝、拼多多 | 用户粘性极强 |
| **转换成本** | 换供应商太麻烦/太贵 | Office软件、苹果生态 | 客户很难离开 |
| **成本优势** | 同样的东西卖更便宜 | Costco、蜜雪冰城、比亚迪 | 规模效应或独特资源 |

### 关键区分：竞争优势 vs 护城河

| | 竞争优势 | 护城河 |
|---------|---------|-------|
| **含义** | 现在比别人好 | 长期保持比别人好 |
| **持久性** | 可能被超越 | 难以被复制 |
| **例子** | iPhone相机拍照好 | 苹果生态系统 |

## 案例分析

### 贵州茅台
| 分析维度 | 情况 |
|---------|------|
| 商业模式 | 生产高端酱香白酒，毛利率90%+ |
| 竞争优势 | 品牌稀缺、不可复制的产地条件、多年储存工艺 |
| 护城河 | 品牌护城河 + 资源护城河（茅台镇地理环境+5年酿造周期） |
| 管理层 | 国企背景，相对稳定，分红大方 |

### 腾讯（微信）
| 护城河类型 | 说明 |
|-----------|------|
| 网络效应 | 用微信是因为朋友、家人、同事都在用 |
| 转换成本 | 离开微信意味着失去社交连接 |

### 苹果
| 护城河类型 | 说明 |
|-----------|------|
| 品牌护城河 | 高端手机的代名词 |
| 转换成本 | iOS生态（App、iCloud、AirDrop等）难以迁移 |

### 拼多多
| 护城河类型 | 说明 |
|-----------|------|
| 网络效应 | 买家越多→卖家越多→商品越多→买家更多 |
| 成本优势 | 拼团模式+补贴，做到全网最低价 |
| 用户心智 | "便宜"这个标签深入人心 |

### 奶茶店品牌（对比案例）
| 品牌 | 护城河类型 | 稳固程度 |
|------|-----------|---------|
| 蜜雪冰城 | 成本优势 | ⭐⭐⭐ 规模极大，供应链成本做到极致 |
| 喜茶 | 品牌心智 | ⭐⭐ "高端奶茶第一品牌"，但可被替代 |
| 霸王茶姬 | 产品差异化 | ⭐⭐ 国风茶饮+鲜奶，但可模仿 |
| 大部分品牌 | 几乎没有 | ⚠️ 所以很多品牌几年就消失了 |

## 理解检查

### 问题1：用奶茶店案例理解公司分析
关注点：产品优势、市场需求、管理层、盈利能力

### 问题2：投资股票就是投资生意
买股票不是买代码，而是成为这家公司的部分所有者。公司赚钱，你才能赚钱。

### 问题3：护城河类型识别
- 茅台：品牌护城河 + 资源护城河
- 腾讯：网络效应
- 苹果：品牌护城河 + 转换成本
- 拼多多：网络效应 + 成本优势

## 知识差距
- 需要更多练习识别不同公司的护城河类型
- 需要学习如何从财报中验证护城河

## 实践应用
- 选股时首先分析公司的护城河类型和稳固程度
- 护城河越深，长期投资价值越大
- 警惕没有护城河的公司，即使短期赚钱也可能很快被超越

## 风险提示
- 好公司不等于好股票 — 价格太贵也不行
- 过去不代表未来 — 诺基亚曾经也是霸主
- 警惕故事型公司 — 只有概念、没有利润的公司要小心
