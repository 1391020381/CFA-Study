# 第05讲：从初创公司到IPO

## 学习日期
2026-02-27

## 核心概念

### 1. 公司生命周期

一家公司从诞生到成熟的完整路径：

```
种子期 → 天使轮 → A轮 → B轮 → C轮 → IPO → 成熟期
  ↓       ↓      ↓     ↓     ↓     ↓      ↓
想法   第一笔钱  扩张   烧钱   冲刺   上市   大公司
```

| 阶段 | 融资轮次 | 特点 | 估值 | 风险 |
|------|----------|------|------|------|
| 种子期 | 创始人自掏腰包 | 只有一个想法 | 最低 | 极高，可能归零 |
| 天使轮 | 天使投资人 | 产品原型 | 几百万-几千万 | 很高 |
| A轮 | VC机构 | 产品有市场验证 | 亿级 | 高 |
| B轮 | VC/PE | 商业模式验证 | 十亿级 | 中高 |
| C轮 | PE | 准备上市 | 百亿级 | 中 |
| IPO | 公开市场 | 向大众发行股票 | 上市定价 | 需要市场验证 |
| 成熟期 | 二级市场 | 稳定盈利 | 市场决定 | 相对低 |

**关键术语**：
- **VC (Venture Capital)**：风险投资，投早期
- **PE (Private Equity)**：私募股权，投后期
- **IPO (Initial Public Offering)**：首次公开募股，上市

### 2. 股权融资：用「股份」换「钱**

**债权融资 vs 股权融资**：
```
方案一：找银行借钱（债权融资）
├── 优点：不用稀释股份
└── 缺点：要还利息，有还款压力

方案二：找投资人拿钱（股权融资）
├── 优点：不用还钱，共担风险
└── 缺点：要稀释股份，让出部分所有权
```

**股权融资的本质**：
```
创始人：100%股份，没钱
       +
投资人：给你1个亿，要20%股份
       =
结果：
├── 创始人：80%股份 + 1个亿现金
└── 投资人：20%股份，成为股东
```

**股份稀释**：
- 每轮融资，公司估值更高，但股份被稀释
- 创始人的股份会越来越少，但总价值可能更高
- 到IPO时，创始人可能只剩10-20%，但公司值几百亿

### 3. IPO流程：从私有到公众

**为什么要IPO？**
| 原因 | 说明 |
|------|------|
| 融资 | 向公众募集资金，用于扩张 |
| 流动性 | 早期投资人可以变现退出 |
| 品牌 | 提升公司知名度和公信力 |
| 激励 | 用股票期权激励员工 |

**IPO流程**（通常需要1-2年）：
```
1. 选定中介机构（券商、律师、会计师）
   ↓
2. 尽职调查（检查公司底细）
   ↓
3. 辅导备案（规范公司治理）
   ↓
4. 制作招股说明书
   ↓
5. 证监会/交易所审核
   ↓
6. 路演（向机构投资者推介）
   ↓
7. 询价定价
   ↓
8. 网上网下发行
   ↓
9. 上市挂牌交易
```

### 4. 估值定价：IPO最关键的环节

**IPO定价 = 公司第一次被市场定价**

定价太低 → 股价暴涨，公司「把钱留在桌上」
定价太高 → 股价破发，投资者亏损，公司信誉受损

**估值方法**：
| 方法 | 适用场景 |
|------|----------|
| PE（市盈率）法 | 盈利稳定的公司 |
| PB（市净率）法 | 金融、周期股 |
| PS（市销率）法 | 还没盈利的成长股 |
| DCF（现金流折现）法 | 现金流可预测的公司 |

**A股IPO的特殊规则**：
- 以前是核准制（证监会说了算）
- 现在科创板/创业板是**注册制**（交易所说了算，更市场化）
- 以前23倍PE上限，现在完全市场化定价

### 5. 一级市场 vs 二级市场

```
一级市场 = IPO发行市场（公司→投资者）
二级市场 = 股票交易市场（投资者↔投资者）
```

**IPO后的股东变化**：
```
IPO前：创始人、VC、PE等少数股东
IPO后：+ 公众股东（成千上万的散户和机构）
```

你在券商APP里买卖的，都是二级市场。

### 6. 新股申购（打新）

**A股打新规则**：
- 需要持仓市值（T-2日前20个交易日日均1万元以上）
- 中签后缴款
- 上市首日可能大涨（科创板/创业板无涨跌幅限制）

**风险提示**：
- 注册制下，新股破发（上市就跌）是常态
- 不要盲目打新，要看公司质量
