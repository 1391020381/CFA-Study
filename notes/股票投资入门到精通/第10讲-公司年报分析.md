# 第10讲：公司年报分析

## 学习日期
2026-02-27

## 核心概念

### 年报是什么
- **年报（Annual Report）**：上市公司每年向投资者公开的"成绩单"和"体检报告"
- 类比：如果你投资一家店，年报就是这家店给所有股东的详细汇报

### 年报的基本结构

| 部分 | 内容 | 重要性 |
|------|------|--------|
| 重要提示和目录 | 公司负责人的致辞、风险提示 | ⭐⭐ |
| 公司简介 | 公司基本情况、主营业务 | ⭐⭐⭐ |
| 会计数据和财务指标 | 核心财务数据摘要 | ⭐⭐⭐⭐⭐ |
| 财务报告 | 三张财务报表及附注（最重要） | ⭐⭐⭐⭐⭐ |
| 董事会报告 | 经营情况、未来规划、行业分析 | ⭐⭐⭐⭐ |
| 重要事项 | 重大投资、诉讼、关联交易等 | ⭐⭐⭐⭐ |
| 股东变动 | 股东结构变化 | ⭐⭐⭐ |

### 初学者阅读顺序
```
1. 先看"会计数据和财务指标摘要" → 了解公司整体表现
2. 再看"董事会报告" → 了解管理层怎么说
3. 最后看"财务报表" → 验证管理层说的是否属实
```

## 关键信息提取

### 1. 看"成绩单"

| 指标 | 看什么 | 好的信号 |
|------|--------|----------|
| 营收 | 是否增长？ | 持续增长 |
| 净利润 | 是否增长？ | 增长速度快于营收 |
| 毛利率 | 是否稳定？ | 稳定或提升 |
| ROE | 是否优秀？ | >15% |

### 2. 看"钱包"

| 指标 | 看什么 | 好的信号 |
|------|--------|----------|
| 经营现金流 | 是否为正？ | 持续为正且增长 |
| 净现比 | 现金流/利润 | >1（赚的都是真钱） |

### 3. 看"风险因素"
- 年报中"可能面对的风险"章节
- 公司自己披露的风险点，非常重要

## 核心洞察

### 为什么经营现金流比净利润更真实？
- **净利润**：包含会计估计和调整（折旧、摊销、应收账款等）
- **经营现金流**：实际收到/支付的现金
- **典型案例**：公司卖出商品确认了收入（利润增加），但如果客户赊账（应收账款增加），实际现金流可能没有增加

> "现金是事实，利润只是观点。"

### 营收增长但净利润增长放缓的原因？
1. 毛利率下降（产品降价或原材料涨价）
2. 期间费用增加（营销、管理费用）
3. 投资收益减少
4. 税收增加

**说明**：公司盈利质量在下降，可能是行业竞争加剧

## 年报分析实战框架

```
第一步：扫视核心数据
│
├─ 营收、净利润增长了吗？
├─ 毛利率、净利率变化了吗？
└─ ROE达到多少？
│
第二步：验证盈利质量
│
├─ 经营现金流是否为正且增长？
├─ 净现比（现金流/净利润）是否>1？
└─ 应收账款是否大幅增加？
│
第三步：看风险和未来
│
├─ 年报提示了哪些风险？
├─ 管理层对未来怎么看？
└─ 行业趋势如何？
│
第四步：做判断
│
└─ 这家公司值得继续跟踪吗？
```

## 年报分析技巧

1. **对比历史**：不要只看一年，要看3-5年的趋势
2. **对比同行**：同行业公司对比，才能知道谁更强
3. **看管理层怎么说**：读"管理层讨论与分析"，判断管理层对行业的把握

### 实战案例：分析茅台年报应关注的指标

| 指标 | 理由 |
|------|------|
| 资产负债率 | 财务风险/杠杆水平，茅台负债率约20%，非常稳健 |
| 营收增长 | 判断业务是否扩张 |
| 经营现金流 | 判断是否赚到"真金白银" |

**补充**：茅台还应关注毛利率（90%+，定价权强）、ROE（25%+，极其优秀）
