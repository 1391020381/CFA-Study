## 核心概念

### 什么是行为经济学？

**传统经济学假设**：人是理性的，会做出最优决策

**行为经济学发现**：人经常不理性，会被各种**认知偏差**影响

```
传统经济学：人 = 理性机器人
行为经济学：人 = 有情绪、有偏见、会犯错的人
```

在投资中，**最大的敌人往往是你自己的人性弱点**。

---

## 一、投资中的六大认知偏差

### 1. 损失厌恶（Loss Aversion）

**核心**：亏钱的痛苦 > 赚钱的快乐

```
实验结果：
├── 亏100元的痛苦 = 赚200元的快乐
├── 也就是说：损失带来的痛苦是同等收益带来快乐的2倍
└── 结论：人天生害怕亏损
```

**投资中的表现**：
- 股票跌了舍不得卖，一直死扛
- 涨了一点点就想落袋为安
- "怕买在半山腰"就是损失厌恶的表现

---

### 2. 羊群效应（Herding）

**核心**：别人都在做，我也想做

**投资中的表现**：
- 2020年大家都在买基金，你也买了 → 高位接盘
- 2022年大家都在骂股市，你也恐慌了 → 底部割肉
- 看到某个股票火了，忍不住追进去

**经典案例：2021年基金热潮**
```
2020-2021年初：
├── 基金上热搜
├── 连地铁阿姨都在谈论基金
├── 大量新人入场
└── 结果：春节后暴跌，套牢无数

教训：不要在大家都在谈论时买入
```

---

### 3. 锚定效应（Anchoring）

**核心**：容易被某个"参考价格"束缚

**例子**：
```
茅台从2600跌到1800
├── 你的"锚"是2600
├── 觉得1800便宜（其实还在高位）
└── 结果：继续跌到1500

问题：你被"2600"这个价格锚定了
```

---

### 4. 处置效应（Disposition Effect）

**核心**：赚了就跑，亏了死扛

```
心理：
├── 赚钱了 → 快点卖，落袋为安（怕利润飞了）
├── 亏钱了 → 不能卖，卖了就成真亏了（死扛）
└── 结果：截断利润，让亏损奔跑

正确做法：
├── 赚钱的股票 → 继续持有，让利润奔跑
├── 亏钱的股票 → 分析原因，该止损就止损
└── 但人性恰恰相反！
```

---

### 5. 过度自信（Overconfidence）

**核心**：高估自己的能力

**表现**：
- "我觉得这只股票能涨"
- "我能在高点卖出"
- "我这次一定没错"
- 结果：频繁交易，佣金没少交，收益却一般

**事实**：
- 80%的散户跑不赢指数
- 但80%的散户觉得自己跑得赢
- 这就是过度自信

---

### 6. 近期偏差（Recency Bias）

**核心**：过度重视最近的信息

**表现**：
- 最近涨了 → 觉得会一直涨
- 最近跌了 → 觉得会一直跌
- 消息好 → 觉得公司前途无量
- 消息坏 → 觉得公司要完了

**问题**：
- 忽略了长期趋势
- 被短期波动牵着鼻子走

## 二、如何克服认知偏差？

### 策略1：建立投资系统

```
问题：靠感觉决策 → 容易被偏差影响
解决：建立规则系统 → 减少情绪干扰

例子：
├── 买入规则：好公司 + 好价格 + PE分位数<40%
├── 卖出规则：公司变坏 / 太贵 / 犯错
├── 仓位规则：单只股票不超过20%
└── 定投规则：每月固定日期买入指数基金

有了规则，就不容易被情绪左右
```

---

### 策略2：分散投资（第18讲）

```
问题：集中持股 → 情绪波动大
解决：分散投资 → 心态平稳

你的配置方案：
├── 35% 沪深300（稳）
├── 35% 红利ETF（稳）
└── 30% 个股（博收益）

好处：
├── 即使个股跌了，整体影响有限
├── 指数部分长期向上，给你信心
└── 心态好了，决策就更理性
```

---

### 策略3：定投策略

```
问题：总想择时（买在最低点）
解决：定期定额买入 → 不猜底

定投的好处：
├── 不需要判断高低点
├── 跌了自动买更多（摊低成本）
├── 涨了买更少（防止追高）
└── 长期持有，必有收获

特别适合：怕买在半山腰的人！
```

---

### 策略4：写投资日记

```
问题：决策时忘了初衷
解决：记录买入理由 → 方便复盘

日记内容：
├── 为什么买这家公司？
├── 什么价格买的？
├── 预期收益是多少？
└── 止损/止盈点位是多少？

以后跌了：
├── 看日记：当初的理由还在吗？
├── 在 → 坚持持有
└── 不在 → 及时止损
```

---

### 策略5：长期视角

```
问题：被短期波动影响情绪
解决：拉长时间维度

数据说话：
├── 沪深300持有1年，盈利概率：约60%
├── 沪深300持有5年，盈利概率：约80%
└── 沪深300持有10年，盈利概率：>90%

结论：
├── 短期：涨跌难预测，心态容易崩
├── 长期：趋势向上，耐心有回报
└── 不要盯着每天的K线图看！
```

## 三、实战案例分析

### 案例1：2021年基金热潮（羊群效应）

```
2020-2021年初：
├── 基金上热搜
├── 张坤、刘彦春等基金经理成明星
├── 连地铁阿姨都在讨论基金
└── 大量新人入场

结果：
├── 2021年2月春节后开始暴跌
├── 许多基金跌30-50%
├── 新人被套在高岗
└── 很多人割肉离场

问题：犯了什么错误？
├── 羊群效应：大家买我也买
├── 近期偏差：看到最近涨得好，觉得会一直涨
└── 没有考虑估值和风险

教训：
├── 不要在大家都在谈论时买入
├── 买在无人问津处
└── 估值和性价比更重要
```

---

### 案例2：死扛亏钱股（处置效应）

```
常见操作：
├── 100元买某股票
├── 跌到80元，觉得会反弹 → 不卖
├── 跌到60元，不甘心 → 不卖
├── 跌到40元，已经麻木了 → 不卖
└── 最后跌到20元，彻底绝望 → 割肉

问题：犯了什么错误？
├── 处置效应：亏了不想卖
├── 锚定效应：锚定在100元的买入价
├── 沉没成本谬误：已经亏了，舍不得认错
└── 没有及时止损

正确做法：
├── 买入前设定止损线（如-20%）
├── 跌到止损位，分析原因
└── 忘掉买入价，只看未来价值
```

---

### 案例3：频繁交易（过度自信）

```
常见操作：
├── 今天买，明天卖
├── 追涨杀跌
├── 觉得自己能抓每个波段
└── 结果：佣金没少交，收益却很少

数据说话：
├── 频繁交易者平均年化收益：约3-5%
├── 买入持有指数年化收益：约8-10%
└── 大部分散户跑不赢指数

问题：犯了什么错误？
├── 过度自信：高估自己的择时能力
├── 忽略交易成本：佣金、印花税
└── 情绪化决策：被短期波动牵着走
```

## 四、投资心理建设

### 心态1：接受不确定性

```
现实：
├── 没有人能预测短期走势
├── 也没人能买在最低点、卖在最高点
└── 承认这一点，你就超越了90%的投资者

做法：
├── 不要追求完美
├── 接受"模糊的正确"
├── 分批买入，不用猜底
└── 长期持有，让时间证明
```

---

### 心态2：独立思考

```
问题：听消息、跟风买入
解决：
├── 别人看好 ≠ 你要买
├── 别人看空 ≠ 你要卖
├── 建立自己的判断体系
└── 基于事实和分析做决策

记住：
├── 投资是认知的变现
├── 别人的钱不是你的钱
└── 独立思考是赚钱的前提
```

---

### 心态3：长期主义

```
短期（1年内）：
├── 涨跌难预测
├── 情绪容易失控
└── 很难赚钱

长期（5年以上）：
├── 趋势可把握
├── 心态平稳
└── 复利效应明显

建议：
├── 不要盯着每日K线
├── 减少看盘频率
├── 专注公司和指数的长期价值
└── 给时间以时间
```

## 五、解决"怕买在半山腰"

### 具体方案

**方案1：分批买入**
```
不要一次性梭哈
├── 第1批：30%（现在买入）
├── 第2批：30%（跌10%再买）
└── 第3批：40%（跌20%再买）

好处：
├── 如果涨了，你也有仓位
├── 如果跌了，你可以摊低成本
└── 心态平衡，不焦虑
```

**方案2：定投**
```
每月固定日期买入固定金额
├── 不管涨跌，坚持执行
├── 跌了买更多份额
├── 涨了买更少份额
└── 长期持有，必有收获

这是克服"择时焦虑"的最好方法！
```

**方案3：买指数，不买个股**
```
个股可能：
├── 退市 → 归零
├── 暴雷 → 跌70%
└── 半山腰之后还有山脚

指数：
├── 永不退市
├── 长期向上
└── 越跌越值得买
```

## 理解检查

### 问题1：为什么"赚了就想跑，亏了就想扛"是错误的？

**答案**：
- 这是对风险的厌恶，持仓风险和心理承受能力不匹配
- 处置效应：过早止盈截断利润，拒绝止损让亏损扩大
- 正确做法：让利润奔跑，及时止损

### 问题2：如果现在市场跌了很多，你很害怕不敢买，应该怎么做？

**答案**：
- 分批买入，保持足够仓位，摊低成本
- 采用定投策略，不需要猜底
- 长期持有，让时间复利发挥作用

## 总结

### 六大认知偏差对照表

| 认知偏差 | 核心问题 | 投资中的表现 | 解决方法 |
|----------|----------|--------------|----------|
| **损失厌恶** | 怕亏钱 | 跌了不敢买，亏了死扛 | 分批买入、定投 |
| **羊群效应** | 从众心理 | 大家买我也买，追涨杀跌 | 独立思考、逆向投资 |
| **锚定效应** | 被参考价束缚 | 被2600的茅台锚定 | 忘掉成本，看未来价值 |
| **处置效应** | 盈亏不对称 | 赚了就跑，亏了死扛 | 让利润奔跑，及时止损 |
| **过度自信** | 高估自己 | 频繁交易，想抓波段 | 承认不足，减少交易 |
| **近期偏差** | 重视近期信息 | 觉得最近趋势会持续 | 长期视角，忽略短期波动 |

### 克服人性弱点的五大策略

```
1. 建立投资系统 → 有规则就不慌
2. 分散投资 → 心态平稳
3. 定投策略 → 不需要择时
4. 写投资日记 → 方便复盘
5. 长期视角 → 给时间以时间
```
