# 第20讲：股指期货与信用交易

### 学习日期
2026-03-04

### 核心概念

#### 期货基础
- **本质**：买卖双方约定未来某个时间点以确定价格交易标的的协议
- **股指期货**：标的是股票指数（如沪深300），现金交割（差价结算）
- **保证金制度**：不需要支付全额，只需支付保证金（如15%）即可控制全额合约
- **自带杠杆**：这是期货的关键特征

#### 融资融券
- **融资（借钱买股）**：向券商借钱买股票
  - 例子：本金10万 + 融资10万 = 20万买股票
  - 股价涨10% → 本金收益+20%
  - 股价跌10% → 本金亏损-20%
- **融券（借股票卖出）**：预计股价下跌，先借股票卖出，跌了再买回来还
  - 风险：理论上亏损无限（股票可能无限上涨）

### 杠杆风险案例

#### 案例1：融资亏损计算
```
本金：10万
融资：10万
总资产：20万买股票

股价跌15%：总资产 = 20万 × (1-15%) = 17万
本金剩余 = 17万 - 10万(融资) = 7万
本金亏损 = 10万 - 7万 = 3万
本金亏损率 = 3万/10万 = 30%

结论：股价跌15%，本金亏30%（2倍杠杆）
```

#### 案例2：强平风险
```
本金：50万
融资：50万
总资产：100万买股票

跌10%后：总资产 = 90万
维持担保比例 = 90万/50万 = 180%

警戒线：130%
平仓线：110%

180% > 130%，不会强平
本金剩余：90万 - 50万 = 40万（亏20%）
```

### 理解检查

- [x] 期货的本质是什么？（未来交货的协议 + 保证金杠杆）
- [x] 融资融券如何放大收益和亏损？（杠杆效应）
- [x] 什么是强平风险？（维持担保比例低于警戒线时券商强制平仓）
- [x] 为什么新手不应该用杠杆？（心理风险 + 财务风险）

### 实践应用

#### ⚠️ 投资纪律
1. **新手不用杠杆**：99%的投资者不具备使用条件
2. **远离期货**：了解即可，不要尝试
3. **警惕他人建议**：别人说赚钱了，不要盲目跟风
4. **慢慢变富**：与其追求暴富，不如稳健投资

#### 杠杆使用条件（成熟投资者标准）
- ✅ 经历完整牛熊周期
- ✅ 稳定盈利3年以上
- ✅ 心理素质过硬（50%回撤不慌）
- ✅ 严格控制比例（不超过1.2倍）
- ✅ 有止损纪律
