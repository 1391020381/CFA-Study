# 第11讲：财务三表分析

## 学习日期
2026-02-27

## 核心概念

### 财务三表的本质（经典比喻）

| 表格 | 比喻 | 本质 | 关键问题 |
|------|------|------|----------|
| **资产负债表** | 一张"照片" | 某个时刻的家底 | 公司有什么？欠什么？ |
| **利润表** | 一段"视频" | 一段时间的业绩 | 公司赚了多少钱？ |
| **现金流量表** | 钱包"流水账" | 现金进出明细 | 钱真的收到了吗？ |

---

## 1️⃣ 资产负债表

### 核心公式
```
资产 = 负债 + 所有者权益
```

> **理解方式**：公司的钱从哪来，用到哪去了？
> - **钱的来源**：负债（借的）+ 所有者权益（股东投的+赚的）
> - **钱的去向**：资产（买的）

### 资产负债表结构

| **资产**（钱的去向） | **负债和权益**（钱的来源） |
|---------------------|--------------------------|
| **流动资产** | **流动负债** |
| - 货币资金（现金） | - 应付账款 |
| - 应收账款（别人欠的） | - 短期借款 |
| - 存货（货） | **非流动负债** |
| **非流动资产** | - 长期借款 |
| - 固定资产（厂房设备） | **所有者权益** |
| - 无形资产（专利品牌） | - 股本（股东投的） |
| | - 未分配利润（赚的） |

### 关键要点
1. **资产排序**：按流动性（现金最容易变现，排前面）
2. **勾稽关系**：资产 = 负债 + 权益（永远相等）
3. **净利润归宿**：利润表的净利润最终会进入"未分配利润"

---

## 2️⃣ 利润表

### 核心逻辑
```
收入 - 成本 - 费用 = 利润
```

### 利润表结构（从上到下）
```
营业收入
  └─ 减：营业成本
  ──────────────
  = 营业利润（毛利）

  └─ 减：销售费用、管理费用、研发费用
  └─ 加/减：投资收益、公允价值变动等
  ──────────────
  = 利润总额

  └─ 减：所得税费用
  ──────────────
  = 净利润
```

### 关键要点
1. **层层剥洋葱**：毛利率、净利率逐层计算
2. **净利润归宿**：最终进入资产负债表的"未分配利润"

---

## 3️⃣ 现金流量表

### 为什么要单独看现金？

> **经典案例**：某公司净利润1亿，但现金流是-5000万。
>
> **原因**：收入都是赊账（应收账款增加），钱还没收到。
>
> **结论**：利润可能是"纸面富贵"，现金流才是"真金白银"。

### 现金流量表结构

```
经营活动现金流
│
├─ 销售商品收到的现金（+）
├─ 购买商品支付的现金（-）
├─ 支付员工工资（-）
└─ 支付税费（-）
│
= 经营活动现金流量净额（最重要！）

投资活动现金流
│
├─ 购买固定资产（-）
├─ 购买理财产品（-）
└─ 处置资产收到的现金（+）

筹资活动现金流
│
├─ 借款收到的现金（+）
├─ 发行股票收到的现金（+）
├─ 分红支付的现金（-）
└─ 偿还债务支付的现金（-）

──────────────────────
= 现金及现金等价物净增加额
```

### 关键要点
1. **经营现金流最重要**：持续为正 = 公司能自己造血
2. **期末现金对应**：现金流量表的期末现金 = 资产负债表的"货币资金"

## 🔗 三表勾稽关系（核心！）

### 勾稽关系图

```
┌─────────────┐
│   利润表    │
│ (一段时间)  │
│             │
│ 净利润 100万│ ─────┐
└─────────────┘      │
                     ▼
              ┌──────────────┐
              │ 资产负债表   │
              │  (某个时点)  │
              │              │
              │ 未分配利润+100万
              └──────────────┘
                     │
                     ▼
              ┌──────────────┐
              │现金流量表    │
              │ (一段时间)  │
              │              │
              │ 期末现金增加 │
              │ → 货币资金   │
              └──────────────┘
```

### 三张表的对应关系

| 利润表 | → | 资产负债表 | → | 现金流量表 |
|--------|---|------------|---|------------|
| 收入 | → | 应收账款增加 | → | 销售收现 < 收入 |
| 成本 | → | 应付账款增加 | → | 购货付现 < 成本 |
| 净利润 | → | 未分配利润增加 | → | 经营现金流增加 |

### 核心洞察

> **三表描述同一件事的三个角度**：
> - 利润表：按会计准则算出来"赚了多少"
> - 现金流量表：实际收到/支付了"多少现金"
> - 资产负债表：时点上的"家底"状态
>
> **如果三表对不上，可能有问题！**

## 📊 财务三表核心指标速查

### 资产负债表指标

| 指标 | 计算方式 | 好的公司 |
|------|----------|----------|
| 资产负债率 | 负债/资产 | <50%（重资产行业可放宽） |
| 流动比率 | 流动资产/流动负债 | >1.5 |
| 应收账款占比 | 应收账款/营收 | <20% |
| 货币资金占比 | 货币资金/总资产 | 越高越安全 |

### 利润表指标

| 指标 | 计算方式 | 好的公司 |
|------|----------|----------|
| 毛利率 | (收入-成本)/收入 | >40%（因行业而异） |
| 净利率 | 净利润/收入 | >10%（因行业而异） |
| ROE | 净利润/净资产 | >15% |
| 营收增速 | (本期-上期)/上期 | 持续增长 |

### 现金流量表指标

| 指标 | 计算方式 | 好的公司 |
|------|----------|----------|
| 经营现金流 | - | 连续为正且增长 |
| 净现比 | 经营现金流/净利润 | >1 |
| 自由现金流 | 经营现金流-资本支出 | 持续为正 |

## 🔍 实战分析框架

```
第一步：看利润表（赚钱能力）
│
├─ 营收在增长吗？
├─ 毛利率、净利率如何？
└─ 净利润多少？
│
第二步：看现金流量表（盈利质量）
│
├─ 经营现金流为正吗？
├─ 净现比（现金流/净利润）>1吗？
└─ 连续3-5年趋势如何？
│
第三步：看资产负债表（财务健康）
│
├─ 资产负债率多少？
├─ 应收账款占比过高吗？
├─ 存货积压吗？
└─ 货币资金充裕吗？
│
第四步：交叉验证（勾稽关系）
│
└─ 三表数据能对应上吗？
```

## ⚠️ 重要警示信号

看到这些信号要警惕：

| 信号 | 可能的问题 |
|------|-----------|
| 净利润增长 + 经营现金流下降 | 利润可能是"纸面富贵" |
| 应收账款增速 > 营收增速 | 赊账销售，产品竞争力弱，可能财务造假 |
| 存货增速 > 营收增速 | 货卖不出去，积压严重 |
| 高利润 + 低货币资金 | 可能有财务造假 |
| 频繁更换审计机构 | 可能有问题隐瞒 |

### 案例：应收账款暴增

**问题**：应收账款从1亿增长到5亿，但营收只增长10%

**分析**：
- 产品无定价权（好产品不愁卖，坏产品才要赊账）
- 现金流紧张，钱都压在应收账款里
- 坏账风险增加
- 可能是虚构收入（财务造假）
