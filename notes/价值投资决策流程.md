# 价值投资决策流程（完整版）

## 创建日期
2026-03-02

---

## 概述

价值投资的核心是：**以低于内在价值的价格买入好公司**

```
核心公式：
投资收益 = 公司业绩增长 + 估值修复 + 分红

价值投资理念：
├── 买股票 = 买公司的一部分
├── 价格 ≠ 价值
├── 安全边际：价格低于价值时才买入
└── 长期持有：让时间复利发挥作用
```

---

## 第一步：分析公司基本面

### 1.1 业务分析（第6讲）

**核心问题**：这是一家什么样的公司？

```
分析框架：

1. 商业模式
├── 怎么赚钱？
├── 盈利模式稳定吗？
├── 现金流模式如何？
└── 行业地位如何？

2. 竞争优势（护城河）
├── 品牌护城河：茅台、格力
├── 网络效应：微信、淘宝
├── 转换成本：银行账号、办公软件
└── 成本优势：拼多多、比亚迪

3. 管理层
├── 诚信度：有没有造假历史？
├── 能力：过往业绩如何？
├── 利益一致性：有没有大量股权？
└── 治理结构：是否规范？

4. 风险因素
├── 行业风险：政策、技术变革
├── 竞争风险：新进入者、替代品
├── 财务风险：负债率、现金流
└── 治理风险：大股东掏空
```

**好公司的标准**：
- 业务简单易懂
- 有护城河
- 盈利稳定
- 负债少
- 管理层诚信

---

### 1.2 财务分析（第7、11讲）

**核心问题**：公司财务健康吗？

```
利润表分析：

1. 收入增长
├── 过去5年收入CAGR是多少？
├── 增长是否稳定？
└── 增长来自量增还是价涨？

2. 盈利能力
├── 毛利率：体现护城河强度
│   ├── >50%：强护城河（茅台90%+）
│   ├── 30-50%：中等护城河
│   └── <20%：竞争激烈
│
├── 净利率：体现成本控制
│   ├── >20%：优秀
│   ├── 10-20%：良好
│   └── <10%：一般
│
└── ROE：巴菲特最看重的指标
    ├── >20%：优秀
    ├── 15-20%：良好
    └── <10%：一般

现金流量表分析：

1. 经营现金流
├── 必须为正（长期）
├── 增长趋势
└── 波动性

2. 净现比 = 经营现金流 / 净利润
├── >1：赚的都是真钱（好）
├── 0.8-1：正常
└── <0.8：需要警惕

3. 自由现金流 = 经营现金流 - 资本开支
├── 必须为正
├── 可以分红、回购、还债
└── 是估值的基础

资产负债表分析：

1. 资产负债率
├── <40%：保守
├── 40-60%：合理
└── >60%：警惕（要结合行业看）

2. 流动比率 = 流动资产 / 流动负债
├── >2：安全
├── 1-2：正常
└── <1：危险

3. 应收账款预警
├── 应收账款增速 < 营收增速：好
├── 应收账款增速 > 营收增速：坏
└── 可能存在虚增收入

4. 商誉
├── 占净资产比例 <10%：安全
├── 10-30%：关注
└── >30%：警惕（可能减值）
```

**财务健康标准**：
- 现金流稳定，净现比>1
- 资产负债率合理
- 应收账款无异常
- 商誉占比低

---

### 1.3 业绩预期

**核心问题**：未来能持续赚钱吗？

```
信息来源：

1. 公司公告
├── 年报、季报
├── 业绩预告
├── 管理层讨论与分析
└── 股东大会交流

2. 券商研报
├── 一致预期（平均预测）
├── 目标价
└── 评级变化

3. 行业数据
├── 行业增速
├── 竞争格局变化
└── 政策影响

4. 宏观环境
├── 经济周期
├── 利率变化
└── 汇率影响

预期判断：
├── 增长期（20%+）：值得给高估值
├── 稳定期（10-20%）：正常估值
├── 成熟期（0-10%）：低估值
└── 衰退期（负增长）：回避
```

## 第二步：估值

### 2.1 选择合适的估值方法

```
公司类型 → 估值方法

银行、保险    → PB估值为主
稳定消费      → PE + PEG
成长股        → PEG + PS
周期股        → PB + 周期位置
亏损公司      → PS + 用户增长
```

| 指标 | 公式 | 适用场景 | 优缺点 |
|------|------|----------|--------|
| **PE** | 股价/每股盈利 | 盈利稳定公司 | 简单直观，但不适用亏损公司 |
| **PB** | 股价/每股净资产 | 银行、周期股 | 适合重资产，但忽略无形资产 |
| **PEG** | PE/增长率 | 成长股 | 结合成长性，但主观性强 |
| **PS** | 股价/每股营收 | 亏损公司、互联网 | 看营收规模，但不看利润 |
| **DCF** | 现金流折现 | 现金流稳定公司 | 理论正确，但假设太多 |

---

### 2.2 相对估值（三维度对比）

#### 维度1：和历史比

```
PE历史分位数：

获取方式：同花顺、东方财富、理杏仁

分位数含义：
├── <20%：极度低估区间
├── 20-40%：低估区间
├── 40-60%：合理区间
├── 60-80%：高估区间
└── >80%：极度高估区间

应用：
├── 分位数低 → 可以考虑买入
├── 分位数高 → 谨慎或卖出
└── 不要在分位数>80%时买入

例子：贵州茅台
├── 当前PE：28倍
├── 历史分位数：50%
└── 结论：合理区间，持有为主
```

#### 维度2：和同行比

```
对比方法：

1. 找同行公司
├── 同行业的其他公司
├── 龙头公司
└── 行业平均

2. 对比指标
├── PE、PB、PS、ROE
├── 增长率
└── 财务健康度

3. 判断
├── 比同行便宜：可能低估
├── 比同行贵：可能是溢价（质量更好）
└── 要深入分析原因

例子：银行股对比
├── 工商银行：PE 4.5倍，PB 0.6倍
├── 招商银行：PE 7倍，PB 1.2倍
├── 建设银行：PE 4倍，PB 0.55倍
└── 结论：招行贵是因为质量好，工行建行便宜但安全
```

#### 维度3：绝对估值（DCF辅助）

```
DCF简化公式：

内在价值 = 未来现金流折现之和

永续增长模型（简化）：
内在价值 = 明年自由现金流 × (1 + 永续增长率) / (折现率 - 永续增长率)

例子：某稳定分红公司
├── 每年分红：1元/股
├── 永续增长：3%
├── 折现率：8%
└── 内在价值 = 1 × (1 + 3%) / (8% - 3%) = 20.6元

判断：
├── 当前价15元 → 被低估
├── 当前价20元 → 合理
└── 当前价25元 → 高估

注意：DCF假设太多，仅作参考
```

---

### 2.3 得出估值结论

```
综合三个维度：

维度          便宜    合理    贵
和历史比      30%    50%    70%
和同行比      便宜   平均    贵
DCF判断       低估   合理   高估

结论：
├── 三个维度都便宜 → 明显低估 → 买入
├── 两个维度便宜 → 可能低估 → 研究后决定
├── 有分歧 → 深入研究原因
└── 都贵 → 高估 → 避开

安全边际：
├── 价格低于内在价值20%以上 → 有安全边际
├── 价格低于内在价值30%以上 → 安全边际充足
└── 宁要模糊的正确，不要精确的错误
```

## 第三步：决策

### 3.1 决策矩阵

```
估值 × 质量 = 决策

好公司（强护城河、盈利稳定）
├── 便宜（<-20%） → 买入/加仓
├── 合理（±20%） → 持有
├── 贵（>+20%） → 观望/减仓
└── 极度贵（>+50%）→ 卖出

一般公司（有一定护城河）
├── 便宜 → 观望/轻仓
├── 合理 → 不买
└── 贵 → 不买

差公司（无护城河、财务差）
├── 便宜 → 不买（价值陷阱）
├── 合理 → 不买
└── 贵 → 远离

核心原则：
├── 好公司 + 好价格 = 好投资
├── 好公司 + 贵价格 = 等待
├── 一般公司 + 便宜价格 = 观望
└── 差公司 + 便宜价格 = 陷阱
```

---

### 3.2 仓位管理

```
原则：不要把鸡蛋放在一个篮子里

单只股票：
├── 核心持仓：10-20%（最有把握的）
├── 卫星持仓：5-10%（看好的）
└── 试探性持仓：3-5%（研究的）

单个行业：
├── 不要超过30%
└── 分散行业降低风险

现金储备：
├── 始终保持10-20%现金
├── 用于下跌时加仓
└── 应对突发情况

分批买入：
├── 第1批：30%（先上车）
├── 第2批：30%（跌10%加仓）
├── 第3批：40%（跌20%加仓）
└── 克服"怕买在半山腰"心理
```

---

### 3.3 买卖纪律

#### 买入条件（同时满足）

```
1. 公司分析：好公司
   ├── 业务简单
   ├── 有护城河
   ├── 财务健康
   └── 管理层诚信

2. 估值：好价格
   ├── 历史分位数<40%
   ├── 或比同行便宜20%+
   └── 或低于内在价值20%+

3. 时机：好时机
   ├── 市场恐慌时（PE分位数<20%）
   ├── 或个股被错杀时
   └── 不要追高

4. 仓位控制
   └── 单只股票不超过20%
```

#### 卖出条件（满足任一）

```
1. 公司变坏
   ├── 护城河消失
   ├── 管理层出问题
   ├── 财务恶化
   └── 行业衰退

2. 太贵了
   ├── PE分位数>80%
   ├── 或比同行贵50%+
   └── 或高于内在价值50%+

3. 犯错了
   ├── 买入理由被证伪
   ├── 发现财务造假
   └── 承认错误，及时止损

4. 找到更好的
   ├── 新机会更好
   └── 仓位有限，需要调仓

核心：
├── 卖出不是因为涨了
├── 也不是因为跌了
└── 而是逻辑变了
```

## 实战案例：腾讯控股

### 第一步：分析基本面

```
业务分析：
├── 社交（微信、QQ）：护城河极强
├── 游戏：现金牛，王者荣耀、和平精英
├── 金融科技：微信支付，增长快
└── 广告：受宏观经济影响
├── 云服务：投入期，增长快
└── 投资：大量投资组合

财务分析：
├── 收入：放缓，增长10-15%
├── 净利润：受投资收益影响，波动大
├── 现金流：强劲，自由现金流>1000亿/年
├── 资产负债：健康，负债少
└── ROE：15-20%（良好）

业绩预期：
├── 监管压力：有所缓解
├── 增长预期：10-15%/年（中低速）
└── 风险：宏观经济、政策、竞争

结论：好公司，护城河强，但增长放缓
```

### 第二步：估值

```
方法：PE + PEG

历史对比：
├── 当前PE：约15倍
├── 历史分位数：约30%（偏低）
├── 历史低点：约12倍（恐慌时）
└── 结论：处于历史低位

同行对比：
├── 腾讯：15倍
├── 阿里：约15倍
├── 美团：约20倍
├── 国际互联网（FAANG）：20-25倍
└── 结论：相对便宜

绝对估值（粗略）：
├── 预期明年每股盈利：约20港元
├── 合理PE：20倍（保守估计）
├── 内在价值：400港元
├── 当前价：约300港元
└── 安全边际：25%

综合结论：被低估，有25%上涨空间
```

### 第三步：决策

```
公司质量：好（强护城河）
估值：低估（-25%）
仓位：假设当前0%

决策：可以买入，分批建仓
├── 第1批：30%（约300港元）
├── 第2批：30%（跌到270港元）
└── 第3批：40%（跌到240港元）

风控：
├── 单只股票不超过20%
├── 保持观察
└── 定期复盘
```

## 克服人性弱点

### 锚定效应

```
错误思维：
├── 我当初100元买的
├── 现在80元，亏了20元
└── 等涨回100元再卖

正确思维：
├── 公司基本面变坏了吗？
├── 未来价值是多少？
├── 当前价80元 vs 未来价值90元
└── 应该持有/加仓（和买入价无关）

核心：忘掉买入价，只看未来价值
```

### 处置效应

```
错误：
├── 赚钱了 → 赶紧卖
├── 亏钱了 → 死扛
└── 结果：截断利润，让亏损奔跑

正确：
├── 赚钱了 → 公司好就继续持有
├── 亏钱了 → 分析原因，该止损就止损
└── 结果：让利润奔跑，及时止损

核心：基于公司价值做决策，不是基于盈亏
```

## 总结

### 价值投资决策流程

```
第1步：分析公司
├── 业务好不好？（商业模式、护城河）
├── 财务好不好？（三表分析）
└── 未来能不能持续？（业绩预期）

第2步：估值
├── 和历史比（分位数）
├── 和同行比（相对估值）
└── 算内在价值（绝对估值）

第3步：决策
├── 好公司 + 好价格 → 买入
├── 好公司 + 合理价格 → 持有
└── 好公司 + 太贵 → 卖出/观望

核心原则：
├── 安全边际：价格低于价值才买
├── 能力圈：只投自己理解的公司
├── 长期主义：给时间以时间
└── 独立思考：不被市场噪音影响
```

### 投资者检查清单

买入前检查：
- [ ] 公司业务简单易懂
- [ ] 有护城河（品牌、网络效应、成本优势）
- [ ] 财务健康（现金流、负债率、应收账款）
- [ ] 管理层诚信
- [ ] 估值便宜（历史分位数<40%或比同行便宜）
- [ ] 有安全边际（价格低于内在价值20%+）
- [ ] 仓位控制（单只股票<20%）

持有期检查：
- [ ] 定期复盘（季度/年度）
- [ ] 跟踪公司公告
- [ ] 关注行业变化
- [ ] 更新估值判断
- [ ] 记录投资日记
